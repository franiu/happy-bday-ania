# 🦌 Ania's Deer Guardian

A touch-friendly browser game where Ania protects deer from giant ticks in a beautiful forest. Swat the ticks before they reach the deer, score 500 points, and unlock a birthday surprise!

## 🎮 How to Play

- **Tap / click** on ticks to swat them before they reach the deer
- Each swatted tick = **+10 points**
- 3 ticks reach a deer → the deer dies
- 3 dead deer → **game over**
- Reach **500 points** to win 🎂

## 🚀 Deploy to GitHub Pages

1. Push this repo to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git branch -M main
   git push -u origin main
   ```

2. Go to your repo on GitHub → **Settings** → **Pages**

3. Under **Source**, select **Deploy from a branch**

4. Pick the **main** branch and **/ (root)** folder, then click **Save**

5. After a minute or two your game will be live at:
   ```
   https://YOUR_USERNAME.github.io/YOUR_REPO/
   ```

That's it — no build step required.
